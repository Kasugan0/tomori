# 03-概要设计

> **适用读者**：架构、新成员、前后端实现者。

---

## 1. 系统架构

单体 **FastAPI + Vue3 SPA + PostgreSQL 17** 应用，AI 视觉推理为**进程内 Python 模块**（`D-37`，不做独立视觉服务）。本地开发栈：`backend` `18141` + `frontend` `15173` + `PG` `25432`；E2E 隔离栈：`18142`/`15174`。

```text
┌───────────────────────────────────────────────────────────────────┐
│                        客户端（Vue 3 SPA + Element Plus）            │
│         src/frontend/src/（views / components / stores / api）       │
└──────────────────────────────┬──────────────────────────────────────┘
                               │ HTTP/JSON (X-Idempotent-Key, JWT Bearer)
┌──────────────────────────────▼──────────────────────────────────────┐
│                    FastAPI Backend（src/backend/tomori）             │
│  api/（薄壳：deps/errors/v1 路由） → services/（重逻辑：状态机/事务）  │
│  models/（SQLAlchemy 17 表） → workers/（notifier / sla_scanner）     │
│  vision/（whitelist → client → mapping → metrics，进程内 ONNX+CV）    │
│  schemas/（Pydantic 出参/错误契约） → db/（base/session/types）       │
└──────────────────────────────┬──────────────────────────────────────┘
                               │ SQLAlchemy Async (psycopg)
        ┌──────────────────────┴──────────────────────┐
        │        PostgreSQL 17.12 (schema.sql)          │
        │  17 表 / 76 CHECK / 41 FK / 37 索引 / 6 部分唯一 │
        │  migrations/versions/0001..0004（Alembic）     │
        └─────────────────────────────────────────────┘

远端训练链（RTX 4080 SUPER）：rsync src → dataset_prep → trainer(yolo train)
   → export ONNX → metrics.json/SHA256SUMS → rsync 回传 → client.py 验收
```

## 2. 源码布局（`src/` 三层）

```text
src/
├── backend/                  # 后端 Python（uv/pip 可安装 src layout）
│   └── tomori/
│       ├── api/              # 薄壳路由 + deps + errors
│       │   └── v1/           # auth / dispatches / health / master_data / operations / tickets
│       ├── services/         # 重逻辑（状态机 / 事务 / 分级 / SLA / 幂等 / 媒体 / 返修）
│       ├── models/           # SQLAlchemy 17 表定义
│       ├── schemas/          # Pydantic 出参/错误契约
│       ├── workers/          # notifier（通知投递）+ sla_scanner（定时 SLA 扫描）
│       ├── vision/           # 视觉模块（13 文件：whitelist/client/mapping/metrics/contract/errors/image_io/baseline/config/eda/dataset_prep/trainer/__init__）
│       ├── db/               # session / base / types
│       └── settings.py       # Settings（.env / application.yml 字段映射）
├── frontend/                 # Vue 3 + TypeScript + Vite + Element Plus（pnpm 独立安装）
│   ├── src/                  # views / components / stores / api / router / main.ts
│   ├── vite.config.ts        # 开发/构建配置（proxy → backend 18141）
│   ├── package.json          # pin 精确版本（D-23）
│   └── dist/                 # 构建产物（gitignored，按需 `pnpm build`）
└── database/
    ├── schema.sql            # 17 表直建 DDL（独立于 Alembic，可 psql 直建）
    └── seed.sql              # 演示种子（3 角色/3 区域/4 账号/6 授权/5 规则/3 点位/2 工单）

config/application.example.yml  # 占位 YAML 配置（__PLACEHOLDER__，.env 映射注释）
migrations/versions/            # Alembic 迁移（0001..0004）
tests/{unit,integration,e2e}    # pytest + pytest-playwright
deploy/                         # stack-guard.sh + compose.yaml + init-dbs.sql
```

### `web/` → `src/frontend`（阶段二布局变更注记）

早期文档中的 `web/` 前端目录已并入 **`src/frontend/`**（同一份 Vue 3 SPA）；`alembic.ini`/`migrations/` 仍在**仓库根**（按 `Lead` 裁决）。运行时产物 `vision/{weights,reports,datasets,runs}`（gitignored）仍在根级 `vision/`。

## 3. 模块划分与职责依赖

| 层 | 模块 | 职责 | 不可为 |
|---|---|---|---|
| **API（薄壳）** | `api/deps.py`/`errors.py`/`v1/{auth,dispatches,health,master_data,operations,tickets}.py` | HTTP→service 调用、Pydantic 参数、幂等键与错误码契约 | 不 `import fastapi.Request/Response` 之外的 DB 会话；不写 `audit_logs` |
| **服务（重逻辑）** | `services/{state_machine,ticket_service,dispatch,rework,sla,grading,auth,media,exceptions}.py` | 状态机唯一入口、单事务不变量、SLA 扫描、确定性分级、幂等、媒体流 | 不经 `transition_*` 改 `status`；不跨事务提交 |
| **模型** | `models/{account,role,account_role,scope_authorization,business_rule,dispatch_record,repair_process,material_usage,acceptance_record,rework_order,fault_evidence,notification_task,audit_log,fault_ticket,maintenance_region,lighting_point,facility_asset}.py` | `17` 表 SQLAlchemy 定义、`76` CHECK/`41` FK/`37` 索引/`6` 部分唯一 | 不写业务逻辑 |
| **Schema** | `schemas/{auth,common,dispatch,master_data,operations,ticket}.py` | Pydantic 出参/错误契约 `response_model` | 不返 ORM 实体直出 |
| **Worker** | `workers/{notifier,sla_scanner}.py` | 通知投递（`process_due_notifications_once`）+ SLA 扫描（`sla_scan`） | 不写 `status` 直改——全部经 `transition_*` |
| **视觉** | `vision/{whitelist,client,mapping,metrics,contract,errors,image_io,baseline,config,eda,dataset_prep,trainer}.py` | 图片四层白名单 → `VisionClient`/`client.py` 推理 → `mapping` 业务枚举 → `metrics` 融合 + `D-30`/`D-31` 契约 | 不产出 `FLICKERING`/`ELECTRIC_HAZARD`（`V3`）；不做独立服务 |
| **DB** | `db/{base,session,types}.py` | `DeclarativeBase` + Async session + 自研 `ARRAY`/`JSONB` 类型 | 不裸 `psycopg` 直查 |
| **前端** | `src/frontend/src/{views,components,stores,api,router}.ts / .vue` | SPA 三角色视图、`128` `data-testid` 冻结锚点、`fallback banner` `MANUAL_REPORT` | 不绕过 `data-code`/`data-fallback-action` 错误提示 |
| **测试** | `tests/{unit,integration,e2e}` | `118` 单测/集成 + `31` E2E 全绿 | 不使用 `mock`/`patch` 替代真实链 |
| **配置** | `config/application.example.yml`、`.env.example` | `__PLACEHOLDER__` 模板 + `Settings` 字段映射 | 真实值不入库 |

### 依赖红线（`docs/DESIGN.md` 局部迁移自阶段一硬纪律）

- `api` 仅可 `import services/schemas/db`；`services` 可 `import models/db/vision`；`models` 仅表定义；`workers` 仅消费 `services/state_machine`；`vision` 进程内函数内延迟导入 `ultralytics`/`onnxruntime`/`cv2`；
- **唯一状态变更入口**：`fault_tickets`/`dispatch_records`/`rework_orders`/`notification_tasks` `status` 更新**只允许**经 `src/backend/tomori/services/state_machine.py` `transition_*()`（`I7`/`I8`）；
- **不变量**：`I1` 同点位同类活跃单一票（`uq_fault_tickets_active_point_type`）/`I4` `ELECTRICAL_SAFETY_CHECK_REQUIRED` 完工前置/`I7` 审计/`I8` 通知。

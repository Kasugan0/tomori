## 1. 数据模型总览（`17` 表 `76` CHECK `41` FK `37` 索引 `6` 部分唯一）

| 类别 | 表 | 核心约束与索引 |
|---|---|---|
| **账号与角色** | `roles`（`code` UNIQUE） / `accounts`（`username`/`employee_no` UNIQUE, `status` CHECK `ACTIVE/DISABLED/LOCKED`, `token_version`） / `account_roles`（`account_id+role_id` 联合唯一） | `uq_accounts_username`/`uq_accounts_employee_no`/`uq_account_roles_account_id_role_id` |
| **授权与组织** | `scope_authorizations`（`account_id+role_id+region_id` 三元唯一，`scope_type`/`is_active`/`valid_from`/`valid_to`） / `maintenance_regions`（`region_code` UNIQUE, `level` CHECK `EXPRESS/MAIN/BRANCH`） | `uq_scope_authorizations_account_id_role_id_region_id` |
| **资产与点位** | `facility_assets`（`asset_code` UNIQUE，`asset_type` CHECK `pole/lamp/cabinet/power`，`importance` CHECK `CRITICAL/HIGH/NORMAL`） / `lighting_points`（`point_code` UNIQUE，`region_id`/`road_level`/`longitude`/`latitude`/`install_height_m`/`lamp_count`/`power_supply_type`） | `uq_facility_assets_asset_code`/`uq_lighting_points_point_code` |
| **工单主链** | `fault_tickets`（`ticket_no` UNIQUE，`status` `9` 态 CHECK，`fault_type` `6` 枚举，`priority` `P1-P4`，`severity`/`repair_deadline_at`/`response_deadline_at`/`closed_at`/`grading_snapshot_json`/`confirmed_by_inspector`/`safety_flag`/`emergency_action_required`/`manual_review_reason`/`cancel_reason`/`manual_note` 各 `CHECK`） | **`uq_fault_tickets_active_point_type`** 部分唯一（`active` 态同点位同类唯一，`I1`） |
| **派工与返修** | `dispatch_records`（`dispatch_no` UNIQUE，`status` `7` 态，`accept_deadline_at`/`accepted_at`/`reject_reason`/`escalate_reason`/`completed_at`） / `repair_processes`（`dispatch_record_id`/`ticket_id`/`electrical_safety_checked`/`safety_checklist_json`/`safety_note`/`root_cause`/`repair_summary`/`repair_started_at`/`repair_finished_at`） / `material_usages` / `rework_orders`（`rework_no` UNIQUE，`round_no`，`requires_manual_review`/`manual_review_decision`/`status` `8` 态，`source_acceptance_id`） | `uq_rework_orders_active_ticket` 部分唯一（活跃返修单同票唯一）；`repair_processes`/`material_usages` FK |
| **验收** | `acceptance_records`（`decision` CHECK `APPROVED/REJECTED`/`comment` `REJECTED` 必填/`rework_order_id` inline FK） | `acceptance_records`/`rework_orders` 循环 FK 方案 B（`task-52`：`acceptance_records.rework_order_id` inline FK + `rework_orders.source_acceptance_id` 后补 FK） |
| **证据** | `fault_evidences`（`evidence_no`/`file_path` UNIQUE，`sha256` UNIQUE，`media_type`/`raw_class`/`is_fault_candidate`/`ai_result_json`/`ticket_id` 可空/`uploaded_by`） | `ticket_id NULL` 行由 `ck_fault_evidences_ticket_or_orphan_inspection` 守卫 |
| **通知与审计** | `notification_tasks`（`task_no`/`status` `5` 态/`event_type` `19` 枚举/`payload_json`/`deep_link`/`retry_count`/`next_retry_at`/`sent_at`/`acknowledged_at`/`dead_letter_reason`） / `audit_logs`（`action`/`entity_type`/`entity_id`/`actor`/`actor_role`/`payload`/`created_at`，append-only） | `notification_tasks.status`/`event_type` CHECK；`audit_logs` 只增不改 |
| **业务规则** | `business_rules`（`rule_code` 唯一 `5` 值 + `rule_value` JSONB + `rule_version`/`is_active`/`updated_at`/`updated_by`） | `uq_business_rules_code_version`/`rule_code` `5` 个默认值（`0004` 迁移 + `seed.sql` 同步） |

## 3. 迁移与初始化

- **Alembic** `migrations/versions/`：`0001_initial_schema`（`17` 表 + `76` CHECK + `41` FK + `24` UNIQUE + `37` 索引）→ `0002_partial_unique_indexes`（`6` 部分唯一：`uq_fault_tickets_active_point_type`/`uq_dispatch_records_active_ticket`/`uq_rework_orders_active_ticket`/`uq_fault_evidences_pending`/`uq_notification_tasks_pending`/`uq_accounts_username_active`）→ `0003_circular_fk_scheme_b`（`acceptance_records.rework_order_id` inline FK + `rework_orders.source_acceptance_id` 后补 FK，`alembic_version.version_num` 列宽 `VARCHAR(32)` 下 `25` 字符迁移名）→ `0004_business_rules_seed`（`5` 条默认 `rule_code` + `rule_value` JSONB）；
- **`schema.sql` / `seed.sql`**：`src/database/` 独立直建脚本（不依赖 Alembic），`seed.sql` 与 `seed_demo_data()` 同构（`3` 角色/`3` 区域/`4` 账号/`6` 授权/`5` 规则/`3` 点位/`2` 工单 + `fault_evidences` × `2`，全部幂等 `ON CONFLICT DO NOTHING`，演示口令 `demo-2026-tomori` 仅本地）；
- **`seed_demo_data()`**：`services/auth.py:251` 服务层播种（`ADMIN`/`INSPECTOR`/`TECHNICIAN` 账号 + `roles`/`regions`/`scope_authorizations`/`business_rules`/`lighting_points`/`facility_assets`/`fault_tickets`/`fault_evidences`），开发栈默认 `seed_demo=true`。

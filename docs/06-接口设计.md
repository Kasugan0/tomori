## 1. `61` 端点清单（`60` 业务 + `health`）

### 1.4 `tickets`（`api/v1/tickets.py`，`19` 端点）

| Method | Path | 角色 | 说明 |
|---|---|---|---|
| `POST` | `/api/v1/tickets/ai-candidates` | `INSPECTOR` | `multipart/form-data`：`files`(1–10)、`lighting_point_id?`、`region_id?`、`scene_lighting_hint`（`auto/day/night/twilight`）——上传→白名单→推理→候选留证或建 `AI_CANDIDATE_PENDING` |
| `POST` | `/api/v1/tickets` | `INSPECTOR`/`ADMIN` | **纯人工报障**（跳过 AI，`confirmed_by_inspector=true` 直接建 `PENDING_DISPATCH`；`fault_type`/`priority`/`title`/`description`/`safety_flag`/`manual_note`/`lighting_point_id`/`facility_asset_id`/`region_id`） |
| `GET` | `/api/v1/tickets` | 已登录 | 工单列表（`status`/`fault_type`/`priority`/`region_id`/`lighting_point_id`/`confirmed_by_inspector`/`created_at` 分页/筛选/排序） |
| `GET` | `/api/v1/tickets/{id}` | 已登录 | 工单详情（`fault_ticket` + `dispatch_records` + `rework_orders` + `fault_evidences` + `acceptance_records`） |
| `PATCH` | `/api/v1/tickets/{id}` | `INSPECTOR`/`ADMIN` | 改 `title`/`description`/`fault_type`/`facility_asset_id`（`FLICKERING`/`ELECTRIC_HAZARD` 必带 `manual_note`） |
| `POST` | `/api/v1/tickets/{id}/confirm` | `INSPECTOR`（`INSPECT`） | `AI_CANDIDATE_PENDING` → `PENDING_DISPATCH`（`grading_rules` 分级快照 + `repair_deadline_at` +48h） |
| `POST` | `/api/v1/tickets/{id}/cancel` | `INSPECTOR`/`ADMIN` | `AI_CANDIDATE_PENDING`/`PENDING_DISPATCH` → `CANCELLED`（`cancel_reason` 必填；`MANUAL_REVIEW` 终止走 `review-resolve`） |
| `POST` | `/api/v1/tickets/{id}/evidences` | 已登录 | 追加上传证据（`upload_ticket_evidences_flow`，终态票 `422 INVALID_STATE_TRANSITION`） |
| `GET` | `/api/v1/tickets/{id}/evidences` | 已登录 | 证据列表（`evidence_no`/`file_path`/`media_type`/`sha256`/`ai_result_json`/`is_fault_candidate`/`created_at`） |
| `GET` | `/api/v1/tickets/{id}/ai-result` | 已登录 | 单图 `FaultCandidateResult` 详情（`bbox_norm`/`bbox_px`/`yolo_confidence`/`fused_confidence`/`visual_signal_state`/`candidate_fault_type`/`suggested_severity_hint`/`opencv_roi_metrics`/`scene_lighting`/`requires_inspector_confirmation`/`replaces_electrical_safety_check`） |
| `POST` | `/api/v1/tickets/{id}/dispatch` | `ADMIN`（`MANAGE`） | `PENDING_DISPATCH`/`REWORK_PENDING_DISPATCH` → `DISPATCHED`（`confirmed_by_inspector` + `TECHNICIAN` 持授权 + `ACTIVE` + 在途 `< 3` + 同票无活跃派工） |
| `GET` | `/api/v1/tickets/{id}/dispatch-candidates` | `ADMIN` | `{candidates[], excluded[]}`，`excluded[].reason` ∈ 5 值枚举 |
| `POST` | `/api/v1/tickets/{id}/regrade` | `ADMIN` | 手工调级（`priority`/`reason` ≥ `10` 字；`grading_snapshot_json` 固化 + `audit_logs`） |
| `POST` | `/api/v1/tickets/{id}/acceptance` | `INSPECTOR`（`INSPECT`） | `decision`=`APPROVED` → `CLOSED`；`REJECTED` → `REWORK_PENDING_DISPATCH` + `rework_orders`（`round_no <= 2` 新轮）/`MANUAL_REVIEW`（`>` 上限） |
| `POST` | `/api/v1/tickets/{id}/review-resolve` | `ADMIN` | `MANUAL_REVIEW` 出口：`APPROVE_REASSIGN`/`SPECIAL_CLOSE`/`TERMINATE_CANCEL`（`reason` ≥ `10` 字） |

| `GET` | `/api/v1/dispatches/{id}` | 已登录 | 派工详情（`dispatch_record` + `ticket` + `technician` + `repair_processes`/`material_usages`） |

| `GET` | `/api/v1/rework-orders/{id}` | 已登录 | 返修单详情（`rework_order` + `ticket` + `acceptance_record` + `repair_processes`/`material_usages`） |

## 2. 统一错误契约

- **`HTTP_STATUS_BY_CODE`（权威 `34` 个 `error.code`）**：`400`/`401`/`403`/`404`/`409`/`413`/`415`/`422`/`429`/`500`/`503` 全覆盖；所有错误响应 `{"error": {"code", "message", "details"}}`；
- **`details.fallback`**：`fallback.action ∈ {"MANUAL_REPORT"}`、`resubmit_required: true`、`message_key`（`vision.disabled.manual_fallback`/`vision.timeout.manual_fallback`/`vision.failed.manual_fallback`）、**不含 `evidence_ids`**；
- **`requires_inspector_confirmation=true` / `replaces_electrical_safety_check=false` / `ai_is_baseline_mode` / `vision_ready` / `disclaimer`**：每图 `ai_result_json` 恒注入。

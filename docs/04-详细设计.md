## 1. 核心流程

### 1.1 AI 报障流程（`POST /tickets/ai-candidates` → `POST /tickets/{id}/confirm`）

| 步 | 处理 | 代码坐标 |
|---:|---|---|
| 1 | `INSPECTOR` 上传 `1..10` 静态图（`multipart/form-data`） | `api/v1/tickets.py:162` `POST /tickets/ai-candidates` |
| 2 | `media.py` 文件大小 `≤15 MiB`（`15,728,640` B）/格式校验 → `whitelist.py` 四层校验（魔数 `:49` → 视频/流字段 `:61-94` → `40MP` 像素 `:147` → `EXIF` 转正 → 解码） | `services/media.py`/`vision/whitelist.py` |
| 3 | 落盘 `uploads/{yyyy}/{mm}/{uuid}.{ext}` + `sha256` + `fault_evidences` 持久化 | `media.py`/`models/fault_evidence.py` |
| 4 | `VisionClient.analyze()`：`nc=3` ONNX + `OpenCV` 融合 → `mapping.py` `map_detection`/`build_result` 业务枚举 | `vision/client.py`/`vision/mapping.py` |
| 5 | 若**无** `is_fault_candidate=true` → `200 {ticket: null, evidences: [...]}`（留证不建票、不锁点位，`D-30`/`FR-15`） | `ticket_service.py`/`ai-candidates` 响应契约 |
| 6 | 否则建票 `AI_CANDIDATE_PENDING` + `fault_evidences` + `audit_logs`（`AI_CANDIDATE_GENERATED`）+ `notification_tasks`（`TICKET_*`）+ `Idempotency-Key` | `ticket_service.py`/`state_machine.py` `create_notification_task`（`:474`） |
| 7 | `INSPECTOR` 逐条 `PATCH`/`confirm`（改 `fault_type=FLICKERING`/`ELECTRIC_HAZARD` 必带 `manual_note`） → `confirm_ticket_flow`（`ticket_service.py:946`）：`grading_rules` 分级快照 + `repair_deadline_at +48h` → `PENDING_DISPATCH` | `tickets.py:626`/`grading.py`/`ticket_service.py:946` |
| 8 | 可选 `dispatch-candidates` 推荐排序（`business_rules['dispatch_scoring_weights'] = (0.40, 0.35, 0.25)`，不改法定时限） | `tickets.py:1020`/`dispatch.py` |
| 9 | `ADMIN` `dispatch`（`confirmed_by_inspector` + `TECHNICIAN` 持授权 + `ACTIVE` + 在途 `< max_active_dispatch` 默认 `3` + 同票无活跃派工）→ `DISPATCHED` + `dispatch_records` + `audit_logs` + `notification_tasks` | `tickets.py:1053`/`dispatch.py` |

### 1.2 派工/维修/验收/返修流程（`B`/`C` 状态机联动）

- `TECHNICIAN` `accept`/`reject`：`DISPATCHED → IN_REPAIR` / `REJECTED`（`reject_reason` 必填，`dispatch_reject_count += 1`）；累计 `>=` 阈值（`dispatch_scoring_weights.max_reject` 默认 `3`）→ `MANUAL_REVIEW`；
- `complete`：`IN_REPAIR → PENDING_ACCEPTANCE`（`electrical_safety_checked=true` + `safety_checklist_json` `5` 项全 `true` + `safety_note`/`repair_summary` 非空 → `422 ELECTRICAL_SAFETY_CHECK_REQUIRED` 缺项全列出）；
- `acceptance`：`APPROVED` → `CLOSED`（`acceptance_records` + `closed_at` + 关联返修置 `PASSED` + `TICKET_CLOSED` 通知）；`REJECTED` → `REWORK_PENDING_DISPATCH` + `rework_orders(round_no)`（`round_no <= 2` 新轮）/`MANUAL_REVIEW`（`> 2` 上限）；
- `MANUAL_REVIEW`：`APPROVE_REASSIGN`（返修置 `CLOSED_BY_REVIEW` + 票回 `PENDING_DISPATCH`）/`SPECIAL_CLOSE`（`reason` ≥ `10` 字，`closed_at` + 关联返修 `CLOSED_BY_REVIEW` + 票 `CLOSED`）/`TERMINATE_CANCEL`（关联返修 `CANCELLED` + 票 `CANCELLED`）。

### 1.3 通知任务流（`D` 状态机，`notifier.py`/`sla_scanner.py`）

`PENDING → PROCESSING（`FOR UPDATE SKIP LOCKED` 抢占）→ SENT / FAILED / DEAD_LETTER`；`DEAD_LETTER` `retry`/`acknowledge`/`process_due_notifications_once`（`notifier.py`）；`sla_scanner` `sla_scan` 定时处理 `accept_deadline`/`repair_deadline`/`ai_candidate_ttl`/`MANUAL_REVIEW` `24h` 催办（最多 `3` 次 → `DEAD_LETTER` → `ADMIN`）。

## 2. `4` 套状态机（`29` 态 / `36` 转移规则条目·`47` `(from,to)` 图边 / `11` 终态 / `0` 死路）

> **口径**：「转移规则条目」按「守卫 + 触发者 + 审计 `action`」为一个编号逻辑规则（`A15+B6+C8+D7 = 36`）；`(from,to)` 字面图边展开为 `47`（`A16+B8+C14+D9`）——部分规则覆盖多条字面边（`A8` 拒单或阈值 → `PENDING_DISPATCH`/`MANUAL_REVIEW` `2` 边；`PENDING_ACCEPT`/`ACCEPTED`/`DISPATCHED`/`IN_REPAIR`/`PENDING_ACCEPTANCE`/`PROCESSING`/`DEAD_LETTER`/`FAILED` 各含多目标边）。

| 机 | 实体 | 状态数 | 规则条目 | 字面图边 | 终态 | 关键守卫/不变量 |
|---|---|---:|---:|---:|---|---|
| `A` 工单 | `fault_tickets.status` | `9` | `15` | `16` | `2`（`CLOSED`/`CANCELLED`） | `A12`/`A13` 同 `acceptance(REJECTED)` 双出口（`round_no <= 2` → `REWORK_PENDING_DISPATCH`，`>` → `MANUAL_REVIEW`）；`MUT-09` 禁 `IN_REPAIR → REWORK_PENDING_DISPATCH`（返修只能由验收驳回触发，保 `rework_count` 语义） |
| `B` 派工 | `dispatch_records.status` | `7` | `6` | `8` | `5`（`REJECTED`/`TIMEOUT_REASSIGNED`/`COMPLETED`/`ESCALATED`/`CANCELLED`） | `B4` 接单超时 `PENDING_ACCEPT → TIMEOUT_REASSIGNED`（防死锁）+ `B7` 管理员 `reassign` |
| `C` 返修 | `rework_orders.status` | `8` | `8` | `14` | `3`（`PASSED`/`CLOSED_BY_REVIEW`/`CANCELLED`） | `IN_MANUAL_REVIEW` → `CLOSED_BY_REVIEW`/`CANCELLED`；`C9`/`C10` 人工出口 + `24h` 催办 |
| `D` 通知 | `notification_tasks.status` | `5` | `7` | `9` | `1`（`SENT`） | `PROCESSING` 出 `4` 边（`SENT`/`FAILED`/`PENDING`/`DEAD_LETTER`），`DEAD_LETTER` 出 `PENDING`/`SENT` |

### `transition_*` 事务模式（`services/state_machine.py`）

- `transition_ticket`（`:725`）/`transition_dispatch`（`:928`）/`transition_rework`（`:1076`）/`transition_notification`（`:1162`）：唯一状态变更入口；`SELECT ... FOR UPDATE` 行锁 + `validate_transition`（`:266`）+ `audit_logs` 写入 + `notification_tasks` fan-out（`enqueue_notifications` `:529`/`create_notification_task` `:474`）；
- `_allowed_from_map`（`:219`）：按 `transitions` dict 计算 `allowed_from`，`INVALID_STATE_TRANSITION` 错误消息含 `from_status`/`allowed_from`；
- **`_TERMINAL_TICKET_STATUSES`**（`services/ticket_service.py:115`）：`{"CLOSED","CANCELLED"}`；`upload_ticket_evidences_flow`（`ticket_service.py:1167`）对终态票传证据直接 `422 INVALID_STATE_TRANSITION`。

### `notifier` / `sla_scanner` 收敛

- `workers/notifier.py`：全部 `task.status` 更新收敛入 `transition_notification`/`create_notification_task`（`rg '\.status\s*=' src/tomori/workers/` → `0` 处直改）；
- `workers/sla_scanner.py`：`sla_scan` 定时批量 `FOR UPDATE SKIP LOCKED` 抢占——`accept_deadline`（`B4` 超时改派）+ `repair_deadline_at`（`I8` 通知，`overdue_stage` 标记不改状态）+ `ai_candidate_ttl_hours`（`CANCELLED` + `AI_CANDIDATE_EXPIRED`）+ `MANUAL_REVIEW` `24h` 催办（最多 `3` 次 → `DEAD_LETTER` → `ADMIN`）。

### 3.3 字段与安全边界

- **`bbox_norm`/`bbox_px` 双坐标系**：`0.0..1.0` 归一化供多端渲染 + 像素坐标（`contract.py` `FaultCandidate`）；
- **`requires_inspector_confirmation=true` / `replaces_electrical_safety_check=false` / `ai_is_baseline_mode` / `vision_ready` / `disclaimer`**：恒注入每图 `ai_result_json`（`contract.py`/`mapping.py`）；
- **`suggested_severity_hint`**：`none`/`P2`/`P3`（`streetlight_on` `none`，`streetlight_damaged` `P2`，`streetlight_occluded` `P3`）；
- **`opencv_roi_metrics`**：`roi_v_mean`/`roi_v_p95`/`bg_ring_v_median`/`luminance_contrast`/`green_foliage_ratio`/`edge_density`/`fusion_status`；
- **`scene_lighting`**：`day`/`twilight`/`night`（`D-31` 不用 `EXIF`，`v_median`/`sky_v_median`/`luminance_contrast`）。

## 4. 异常处理（`AppError` `34` 码 + `details`/`fallback`/`MANUAL_FALLBACK`/`resubmit_required`/`DEAD_LETTER`）

| 层级 | 机制 | 代表 `error.code` |
|---|---|---|
| **`AppError`** | `errors.AppError(code, http_status, message, details)`，`HTTP_STATUS_BY_CODE` 权威 **`34` 个错误码** | `403 FORBIDDEN_REGION_SCOPE`/`409 DUPLICATE_ACTIVE_TICKET`/`422 INVALID_STATE_TRANSITION`/`422 AI_CANDIDATE_NOT_CONFIRMED`/`422 ELECTRICAL_SAFETY_CHECK_REQUIRED`/`422 RULE_VALUE_IMMUTABLE`/`422 IDEMPOTENCY_PAYLOAD_MISMATCH`/`409 IDEMPOTENCY_REQUEST_IN_PROGRESS`/`415 UNSUPPORTED_IMAGE_FORMAT`/`415 MEDIA_VIDEO_STREAM_FORBIDDEN`/`422 IMAGE_PIXEL_LIMIT_EXCEEDED`/`413 IMAGE_SIZE_EXCEEDED`/`503 VISION_DISABLED`/`503 VISION_TIMEOUT`/`503 VISION_INFERENCE_FAILED` |
| **`details.fallback`** | 视觉降级契约 `D1`–`D3`：`fallback.action == "MANUAL_REPORT"`、`resubmit_required == true`、非空 `message_key`（`vision.disabled.manual_fallback`/`vision.timeout.manual_fallback`/`vision.failed.manual_fallback`），**不含 `evidence_ids`**（文件已回滚） | 前端锚点 `data-testid="inspection-vision-disabled"`（`src/frontend/src/views/inspection/InspectionReportView.vue:660`）+ `data-code`/`data-fallback-action="MANUAL_REPORT"` |
| **`resubmit_required`** | `true` = 前端携原文件走 `POST /tickets` 人工重投（兜底建票） | `D3` |
| **`DEAD_LETTER`** | `PROCESSING`/`FAILED`/`DEAD_LETTER` 三态——`retry`/`acknowledge`/催办 `24h`/`ADMIN` 通知 | `notification_tasks` `D7`/`D8`/`D9`/`D10` |

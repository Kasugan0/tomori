## 1. 角色与权限模型

| 角色 | `code` | 职责 | 关键不可为 |
|---|---|---|---|
| `ADMIN` | `ADMIN` | 全域配置、`business_rules` 管理、派单、人工复核、返修决断 | 不得经 `PATCH` 修改 `audit_logs`/`notification_tasks` 历史记录 |
| `INSPECTOR` | `INSPECTOR` | 现场拍照上报（`POST /tickets/ai-candidates`、`POST /tickets`）、AI 候选确认/修改/取消、`acceptance` 验收 | 不得绕过 `confirmed_by_inspector=true` 建派工单；不得越过区域授权 |
| `TECHNICIAN` | `TECHNICIAN` | 接单/拒单、`complete` 维修、`escalate` 升级 | 不得跳 `electrical_safety_checked=true` 完工；不得自我返修（`MUT-09`） |

- **`scope_authorizations`**：`roles` × `maintenance_regions` 三层业务范围授权（`MANAGE`/`INSPECT`/`REPAIR`），`api/deps.py` `FORBIDDEN_REGION_SCOPE` 等守卫；`ADMIN` 全域、`INSPECTOR`/`TECHNICIAN` 按区域。
- **账号生命周期**：`ACTIVE`/`DISABLED`/`LOCKED` + `token_version` 吊销（`/auth/logout` 单点吊销）。

## 3. 业务规则（`business_rules` `5` 默认值）

| `rule_code` | `rule_value`（默认） | 用途 |
|---|---|---|
| `grading_rules` | `144` 枚举组合（`fault_type` × `road_level` × `safety_flag` → `P1`–`P4`） | `FR-17`/`FR-18` 确定性分级 |
| `sla_policy` | `repair_deadline_at = confirmed_at + 48h`（`D-11`，法定 `2880` 分钟） | 全单法定时限 |
| `dispatch_scoring_weights` | `(0.40, 0.35, 0.25)` 推荐排序权重 | `dispatch-candidates` 排序推荐（不影响 48h 时限、不拦人选） |
| `rework_policy` | `max_rework_rounds = 2` | `FR-23` 返修轮次上限 |
| `ai_candidate_ttl_hours` | `72` | `FR-14` 候选过期自动 `CANCELLED` |

- **`422 RULE_VALUE_IMMUTABLE`**：`rule_value` 禁原地改（版本化新增），`audit_logs` 全量落变；
- **`retry`/`acknowledge`**：`DEAD_LETTER` `PROCESSING → retry / acknowledge`（`operations.py` 端点），`notification_tasks` 最多 `3` 次进死信。
